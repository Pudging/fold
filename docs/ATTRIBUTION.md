## Original project work

Fold combines a Catan-style economy and road graph with location-qubit settlements, legal site reservations, phase/interference actions, gate ports, joint production measurement, and state-derived indicators. The terrain graphics are original SVG artwork.

This is an independent prototype, not an official CATAN product. Familiar board-game rules are a starting point; no claim is made to invent settlement/trading games or quantum gates. See the [official CATAN rules](https://www.catan.com/understand-catan/game-rules).

## Tools and dependencies

- Qiskit provides independent numerical validation and the Python backend circuit path.
- Vite builds the JavaScript app.
- Manrope is loaded through Google Fonts with a sans-serif fallback.
- The separate video project uses React, Remotion and its dependencies; dependency licenses remain their own. The project's original code/documentation is MIT, which does not relicense third-party packages.

See both package-lock files for exact JavaScript dependency versions.
